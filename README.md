# 小舟 · Kobune Sushi

一家可以“走进去”的微缩手作风日式寿司小店网页。把鼠标移到店里的东西上探索，点击即可互动。

线上地址：https://jacey-dai.github.io/izakaya-shop/

## 能做什么

| 店里的东西 | 互动 |
| --- | --- |
| 暖帘 | 店铺介绍和玩法说明 |
| 门口立牌（黑板） | 今日鲜货（按日期每天变化），竖排粉笔字菜单 |
| 墙上木札 | 一品料理与甜品 |
| 酒架 | 饮品单 |
| 桌面菜单 | 带分页签的完整菜单册，含定食套餐（约 85 折） |
| 鱼柜 | 自选鱼生：挑鱼放进盘子，拼一份专属刺身 |
| 春田师傅 | 聊天；おまかせ（师傅推荐），有机会遇到菜单上没有的传说之鱼；积分卡集满 10 个可以找他抽奖 |
| 座位 | 吧台席 / 和室座敷，选座后场景里会出现你的位置 |
| 挂轴 | 鱼图鉴：吃过的鱼会被收录，含日语名、英语名、口感、风味、旬 |
| 招财猫 | 抽签，运气会提升师傅推荐的稀有度 |
| 你自己 | 选座后坐在店里（背影），可以换发型、发色、衣服和配饰，也可以填生日 |

顶栏可以切换中文 / English。图鉴进度保存在浏览器本地（localStorage），换设备或清除浏览器数据会丢失，详见 PRD §5.5。

## 本地运行

纯静态页面，没有构建步骤。直接双击 `index.html`，或者：

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000
```

## 怎么扩展

- **加鱼 / 改鱼的介绍**：编辑 `js/data.js` 里的 `fish` 数组。刺身菜单、鱼柜、图鉴都会自动更新。
  `omakaseOnly: true` 的鱼只能通过师傅推荐获得。
- **加菜 / 改价格**：编辑 `js/data.js` 里的 `menu`。套餐在 `sets`，价格自动按 85 折计算。
- **改积分卡奖品和概率**：`js/data.js` 里的 `prizes`，`weight` 是百分比。
- **改师傅台词、抽签结果**：`js/data.js` 里的 `chef` 和 `omikuji`。
- **英文**：内容翻译在 `js/data.en.js`，界面文案在 `js/i18n.js`。加中文时记得同时加英文。
- **改场景**：本地 `assets/art/izakaya-room.webp` 底图、`assets/art/haruta.webp` 男性春田角色，以及 `index.html` 里的 `<svg class="scene">` 热点图层。美术来源在 PRD §11 登记。每个可互动的东西是一个
  `<g class="hotspot" data-id="...">`，悬停提示写在 `data.js` 的 `hotspots` 里，
  点击后打开 `js/app.js` 里同名的 `views.<id>`。

## 文件结构

```
assets/art/     本地微缩场景与男性师傅 WebP
index.html      页面和店内场景（SVG 热点 + 素材图层）
css/style.css   样式
js/i18n.js      界面文案（中 / 英）
js/data.js      鱼、菜单、座位、台词等所有内容数据（中文）
js/data.en.js   内容数据的英文翻译
js/app.js       交互逻辑
docs/PRD.md     完整产品需求文档（多 agent 协作请先读）
CLAUDE.md       给 agent 的入口说明（AGENTS.md 内容相同）
```

## 视觉与范围（v0.1.5）

采用温暖的微缩手作风：奶油白、蜂蜜木色、靛蓝、陶土红，局部暖光、棉麻与陶器质感。
师傅轻微呼吸、蒸汽与灯光支持系统“减少动态效果”。手机上吧台场景可以横向滑动，点击店内物件即可互动。

当前默认角色是男性春田。“当 chef / 当顾客”和玩家性别选择仍属于 PRD T-10 的后续功能，本次不实现。
场景和师傅素材保存在仓库本地，不需要联网加载图片或 Three.js。现有点餐、堂食 / 外带、抽签、图鉴和本地存档保持可用。

## 浏览器回归检查

运行环境需要 Node.js 和 Playwright（仅用于测试，应用本身没有新增依赖或构建步骤）：

```bash
# Playwright 已安装且 Chromium 可用时
node tests/smoke.cjs

# 也可复用外部安装，指定本机 Chrome
PLAYWRIGHT_MODULE=/absolute/path/to/playwright \
CHROME_EXECUTABLE=/absolute/path/to/chrome \
node tests/smoke.cjs
```

脚本直接用 `file://` 打开页面，覆盖中英热点、键盘、点餐、拼盘限制、师傅推荐、堂食 / 外带、客人自定义、存档、390px 手机弹窗和减少动态效果。截图写入 `/tmp/kobune-*.png`。

## 和室座敷视角（v0.1.7）

选择「和室座敷」后，会进入完整的榻榻米房间，刷新后保持。桌上的菜单、茶具、空刺身盘和服务铃分别可以看菜单、点饮料、自选鱼生、呼叫师傅；挂轴、招财猫等也可继续互动。
点击房间上方「回到吧台席」，或在座位选择中改选吧台，即可切回原场景。换座不清空订单或收集进度。手机上座敷全景适配屏幕，原吧台仍可左右滑动。

## 玩偶客人与换装（v0.1.8）

客人现在与春田师傅一样采用微缩手作玩偶画风，带有立体发束、针织与和服布料纹理。四种发型、三种服装、全部发色 / 衣色、帽子和发簪仍可自由组合，原有形象存档继续有效。
吧台和座敷分别调整人物大小，让前景客人与师傅、凳子、坐垫的比例更协调；换装预览与场景同步。素材来源见 PRD §11。

## 场景细节修正（v0.1.9）

帽子按发型单独适配，并隐藏帽冠内头发，修复短发和长发的穿模。黑板上的文字缩小并贴合板面，不再压住木框。
页面已移除底部四个快捷按钮、标语、上方操作提示和可见房间标题。点击场景物件继续点餐、聊天、抽签；座敷仍保留返回吧台按钮。

## 上菜（v0.2.0）

结账后订单弹窗先关上，春田把木屐盘（打包则是外带盒）送到你的座位，然后才弹小票。盘子会留在座位上，点一下吃掉一贯，全部吃完后春田会把空盘收走；外带盒点一下就带走。开启“减少动态效果”时盘子直接出现。

坐在吧台高凳上时，客人是垂着腿坐的；坐在和室座敷里则是盘腿坐。

## 人物动作（v0.2.1）

进店时春田鞠躬说「いらっしゃい！」，坐着的客人会招手；下单后春田先切鱼、捏寿司再端盘；客人吃的时候会点头嚼，吃完开心地跳一下。开启“减少动态效果”时这些动作都会关掉。

## 套餐和积分卡（v0.2.4）

菜单册的「定食」页有刺身定食、握寿司定食、天妇罗定食和おまかせ套餐，比单点便宜约一成半。前两种的鱼每天固定，页面上会写今天是哪几种；おまかせ套餐点的时候由师傅现挑。

每次下单在积分卡上盖一个章，点了おまかせ套餐多盖一个。集满 10 个后，从师傅弹窗打开积分卡，找春田摇抽奖箱：消费券 50%、撸猫券 30%、玩偶公仔 15%、免费吃一顿 5%。抽到的奖品收在积分卡页，怎么使用还待定（PRD Q14）。

## 拍照、生日和离线（v0.2.5）

- **拍照**：顶栏「拍照」把当前场景存成一张带店名、日期和座位的图片，可以保存或分享。直接双击本地文件打开时浏览器不允许拍照，要用线上地址或本地服务器（如 `npx serve`）。
- **生日**：在换装弹窗里填生日。生日当天坐下后，春田会端上一盘插着蜡烛的玉子烧，一年一次。
- **离线**：用线上地址打开过一次后，断网也能打开。手机浏览器可以“添加到主屏幕”。发布新版本时 `sw.js` 里的 `VERSION` 要和 `index.html` 的 `?v=` 一起改。

## 节日和下雨天（v0.2.6）

店里会按真实日期换装饰：正月门松、春天飘樱花、七夕竹枝、万圣节南瓜灯、圣诞小树。有些日子会下雨：障子和窗外有雨，暖帘滴水，门口放着湿雨伞，春田会推荐热茶和热菜。想提前看可以在地址后面加参数，例如 `index.html?date=2026-07-05&weather=rain`。改节日在 `js/data.js` 的 `festivals`。

## 当厨师（v0.2.7）

在暖帘或顶栏「身份」里选「厨师」，就换你站到吧台后面。客人坐下点一份刺身拼盘，点春田或客人可以看单子，点鱼柜开始摆盘：点鱼切一片，拖到盘子上，滚轮或「旋转」转方向，也可以清空、打乱重摆。上菜后客人按像不像订单打 1–3 星，吃完下一位客人进店。端出去的鱼也会收进图鉴，三星还多盖一个积分章。现在只有男版春田，女厨师形象画好后再加。

## 统一微缩美术与店猫（v0.2.8）

寿司、刺身和生日玉子烧改用原创微缩食物素材，保留每种鱼的颜色与既有菜单。春田切鱼、捏寿司、递盘时使用独立姿态及局部手部层；客人的衣袖和筷子跟随进食动作，鱼片从盘中送到嘴边。人物动作按角色排队，减少动态效果时跳过。

橘白店猫会在两间房的空地上走动、蜷睡。点击或用键盘选中后按 Enter / 空格，它会眯眼回应并发出短促的合成喵声；没有自动播放的声音。店猫与招财猫抽签是两个独立入口。新素材均在本地和离线缓存中，双击 `index.html` 也能运行。

美术回归：`PLAYWRIGHT_MODULE=/path/to/playwright CHROME_EXECUTABLE=/path/to/chrome node tests/miniature.cjs`，验证店猫实际点击、双语键盘反馈、人物局部层、食物边界和减少动态效果。

## 坐姿与天气修正（v0.2.9）

吧台十二种换装改为完整高凳坐姿，不再裁掉盘腿后拼小腿。问候为轻点头，进食为轻微欠身，不再叠加会断开的手臂；座敷保持完整盘腿人偶。动作以座面为固定点，结束平滑回到原姿态。

万圣节使用有釉面和内部烛光的微缩陶瓷南瓜灯；雨天使用湿布雨伞和仅覆盖门窗的景深雨景，移除平铺白线和卡通水滴。原房间布置、热点、节日日期与雨天规则保持不变。

`tests/guest-weather.cjs` 逐帧检查问候座面锚点、十二种高凳造型、雨景素材、晴天和减少动态效果；运行环境变量与 smoke 测试相同。

## 背影坐姿与凳子遮挡（v0.2.10）

吧台人物和凳子共同绘制，大腿朝向吧台，膝盖及小腿位于远侧，从背后只露鞋跟或足袋后侧；凳沿、凳腿正确遮挡腿部。占座后只替换中间一张凳子，避免新旧凳面重叠。问候只动上半身，凳子保持稳定。新图集采用独立文件名，避免继续读取旧脚部素材。十二种换装、配饰、座敷坐姿与存档均保留。

`tests/rear-seat.cjs` 检查所有换装的唯一凳子图层、问候期间固定的凳子变换、上半身动作、戴帽红色浴衣、换座与刷新。
