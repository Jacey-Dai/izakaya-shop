# 小春鮨 PRD

## 目标

做一家呈现在网站上的日式寿司小店。整体日式风格，访客可以用鼠标在店里探索，
点菜、自选鱼生，并以图鉴的形式收集吃过的鱼生和刺身。

## 第一版（已完成）

- 可探索的店内场景：悬停高亮 + 提示，点击打开对应内容
- 多种菜单呈现方式：门口黑板立牌、墙上木札、酒架饮品单、桌面菜单册
- 日料师傅：对话、今日鲜货、おまかせ推荐
- 座位：吧台席 / 和室座敷
- 自选鱼生：从鱼柜挑鱼拼盘
- 点单 → 选座 → 下单流程
- 鱼图鉴：稀有度（並 / 上 / 特上 / 幻），每种鱼有中文名、日语名（假名 + 汉字 + 罗马音）、
  英语名、口感、风味、旬、介绍；部分鱼只在师傅推荐中出现
- 招财猫抽签，影响师傅推荐的稀有度

## 待办想法（暂不执行）

### 摆盘与上菜：当 chef 还是当客人

在选择鱼生时，让用户选择自己的角色：

- **当 chef**：用户自己摆盘 / 做菜。
  - 自行摆盘：把鱼片拖到盘子里的任意位置，调整角度和层叠
  - 重新摆盘：清空或打乱后重摆
  - 上菜：完成后把盘子端给客人（可以有客人的反馈或评分）
- **当客人**：由师傅摆盘、上菜，用户只负责挑鱼和享用
  （接近当前版本的体验，可以加入上菜动画）

需要确定的问题：
- 两种角色的入口放在哪里（进店时选择？鱼柜里切换？）
- 当 chef 时是否有评分 / 挑战机制，是否影响图鉴收集
- 摆盘结果是否可以保存或分享

## 其他可以考虑的方向

- 更多座位类型、可以看到其他客人
- 季节限定的鱼（按真实月份出现）
- 图鉴集齐奖励、成就
- 背景音乐和音效（切鱼、门铃、"いらっしゃいませ"）
